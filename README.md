🍕 Pizzeria BackendEin modernes Spring Boot Backend für ein Pizzeria-Bestellsystem.Tech-Stack: Java 21, Spring Boot 3.4.5, PostgreSQL, JWT Auth, MapStruct & Lombok.🛠 Setup & StartWir nutzen verschiedene Docker-Konfigurationen, je nachdem, wie du entwickeln möchtest.1. Hybrid-Modus (Entwicklung in der IDE)Nutzt Docker nur für die Datenbank und Adminer. Das Backend wird direkt in IntelliJ/Eclipse gestartet.Start: docker compose up -dBackend-URL: http://localhost:8081Adminer: http://localhost:8085 (Postgres auf Port 5433)2. Full Docker Modus (Standalone)Startet das komplette System inkl. Backend in Docker. Ideal für Tests ohne lokale Java-Installation.Start: docker compose -f docker-compose.full.yml up -d --buildBackend-URL: http://localhost:8082Adminer: http://localhost:8086Logs verfolgen: docker logs -f pizzaria-backend-full3. Codespace (Cloud)Start: docker compose -f docker-compose.codespace.yml up -d📖 API-Dokumentation (Swagger)Das Projekt nutzt SpringDoc OpenAPI. Sobald das Backend läuft, kannst du die API interaktiv im Browser testen:Swagger UI: http://localhost:8082/swagger-ui.htmlOpenAPI JSON: http://localhost:8082/v3/api-docsHinweis: Im IDE-Modus Port 8081 verwenden.🧪 API-Tests mit BrunoWir nutzen den Bruno API Client (Offline-First Alternative zu Postman). Die Test-Requests sind direkt im Repository eingecheckt.Installiere Bruno.Wähle "Open Collection" und öffne den Ordner /api-requests in diesem Projekt.Wähle oben rechts das Environment "Docker-Local" (für Port 8082).Auth: Nutze den /auth/login Endpunkt, um einen JWT-Token zu erhalten. Die Collections sind so vorkonfiguriert, dass der Token automatisch für Folgerequests übernommen wird.🚀 Wichtige BefehleZielBefehlAlles neu bauen & startendocker compose -f docker-compose.full.yml up -d --buildLogs live verfolgendocker logs -f pizzaria-backend-fullSystem stoppen (Daten behalten)docker compose -f docker-compose.full.yml stopSystem beenden (Container löschen)docker compose -f docker-compose.full.yml downHard Reset (Inkl. Datenbank-Löschung)docker compose -f docker-compose.full.yml down -v🛡 Security & JWTDie API ist durch Spring Security geschützt.Öffentlich: /auth/**, /products (nur GET), /v3/api-docs/**, /swagger-ui/**.Geschützt: Alle anderen Endpunkte benötigen einen gültigen Bearer Token im Header.Admin: Endpunkte unter /admin/** erfordern die Rolle ROLE_ADMIN.
